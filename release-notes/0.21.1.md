# etcds 0.21.1

2026-10-17.

## New

- **Metrics** (feature `tracer`): counters and timings of the KV calls, on the OpenTelemetry
  meter the host hands over.
- **A policy for key prefixes**: which keys stay on their node, and which are served only to a
  local caller.

## Changed

- 0.21.2 (2026-10-24): the YAML reader is serde-saphyr, and the crate forbids unsafe code.
- 0.21.3 (2026-10-25): messages in six languages, each error with a code (`ETCD-Ennn`).
